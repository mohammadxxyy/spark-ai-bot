# 🚀 بوت تيلجرام Spark AI (للتسويق الرقمي والإعلانات الممولة)

بوت تيلجرام متكامل ومخصص لخدمة العملاء وأخذ طلبات الحملات الإعلانية الممولة (Paid Ads) وأتمتة العمليات لشركة **Spark AI**.

---

## 🌟 ميزات البوت لشركة Spark AI

### 1. 💼 استعراض الخدمات الإعلانية والباقات
- **إعلانات ميتا (Meta Ads):** إنستغرام وفيسبوك، إعداد وتتبع Conversions API، وإعلانات الريلز.
- **إعلانات تيك توك وسناب شات:** استهداف الفئات الشبابية ومحتوى UGC عالي التحويل.
- **إعلانات جوجل واليوتيوب (Google Ads):** استهداف نية الشراء وحملات Performance Max.
- **باقة النمو الشاملة (Full Growth 360°):** إدارة الحملات والتصاميم وصفحات الهبوط وأتمتة المبيعات.
- **صناعة المحتوى الإعلاني والتصاميم:** نصوص إعلانية بياعة وفيديوهات جذابة.
- **أتمتة الردود والمبيعات:** روبوتات محادثة للرد الفوري 24/7 وجمع بيانات العملاء.

### 2. 💡 حاسبة وتوصية المنصات الإعلانية
- استبيان سريع يحدد للعميل أفضل المنصات والميزانية المبدئية المقترحة حسب مجاله (متاجر إلكترونية، عيادات ومراكز تجميل، عقارات، خدمات B2B).

### 3. 📝 مسار طلب حملة جديدة (Order Intake Automation)
- نظام تفاعلي خطوة بخطوة:
  1. اختيار نوع الخدمة الإعلانية.
  2. إدخال اسم النشاط التجاري والمجال.
  3. تحديد المنصات المستهدفة (أو تركها لتوصية الفريق).
  4. إدخال الميزانية الإعلانية التقريبية والهدف (مبيعات / رسائل / انتشار).
  5. إدخال بيانات الاسم ورقم الواتساب أو الهاتف.
  6. مراجعة ملخص الحملة وتأكيدها.
  7. إصدار كود متابعة مميز للعميل بصيغة: `SPARK-MKT-XXXX`.
  8. إرسال إشعار فوري وتلقائي لإدارة التسويق.

### 4. 🗄️ قاعدة بيانات SQLite مدمجة (`spark_marketing.db`)
- حفظ كامل لجميع الطلبات وتفاصيل الاتصال والميزانيات وتواريخ التسجيل وحالات الحملات.
- إمكانية استعلام العميل عن حالة طلبه عبر البوت بكود المتابعة في أي وقت.

### 5. 🛠️ لوحة تحكم الإدارة
- أوامر خاصة للمسؤولين:
  - `/admin` أو `/orders`: عرض آخر الطلبات المسجلة مع أرقام هواتف العملاء والميزانية والحالة الحالية.
  - تعيين `ADMIN_CHAT_ID` في ملف `.env` لاستلام تنبيهات فورية عند وصول أي طلب جديد.
